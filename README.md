# Beyond_the_Board
This is a repo for a game that is like chess but the pieces have a mind of their own. So not only are you going against an AI opponent but also potentially your own pieces


## Open and run the project

Use Unity 6000.5.10f1 (see ProjectSettings/ProjectVersion.txt). Clone the repository and open its folder in Unity Hub; Unity resolves the packages listed in Packages/manifest.json, including the Input System used by the piece scripts. On the julian/mage-agent branch, open Assets/Test.unity and press Play to run the Mage demonstration. See MAGE_AGENT.md for its behavior and tuning options.
